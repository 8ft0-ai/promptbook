# Conditional Promptbook contracts

These are live, conditionally applicable instruction sources owned by Promptbook, not duplicate V1 policy engines. The canonical [workflow router](../../prompts/workflows/README.md) selects which details are required. [Autonomous progression](../../prompts/workflows/autonomous-progression.md) owns ordinary goal execution and [resolved context](../../prompts/workflows/resolved-agent-run-context.md) owns the derived action/evidence gateway. Each selected specialist clause is mandatory when its stated trigger is met; do not load unrelated clauses.

Do not infer mutation, approval or execution permission from any reference or selected guide.
